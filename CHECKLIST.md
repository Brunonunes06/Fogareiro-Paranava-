## 🔧 Troubleshooting Rápido

### Problema: Site não abre

**Solução:**
1. Verifique se `index.html` existe
2. Teste em outro navegador
3. Limpe cache (Ctrl+Shift+Del)
4. Verifique console para erros (F12)

### Problema: Estilos não aparecem

**Solução:**
1. Confirme `styles.css` está na mesma pasta
2. Verifique nome do arquivo (sem espaços)
3. Recarregue a página (Ctrl+F5)
4. Abra console para erros 404

### Problema: Menu não funciona no mobile

**Solução:**
1. Verifique `script.js` está carregando
2. Procure erros no console
3. Teste em outro navegador mobile
4. Verifique se jQuery não está conflitando

### Problema: Links não funcionam

**Solução:**
1. Verifique números telefônicos
2. Confirme links completos (com http://)
3. Teste URLs em abas novas
4. Verifique conexão à internet

### Problema: Imagens não aparecem

**Solução:**
1. Confirme caminho correto
2. Arquivo existe na pasta
3. Verifique extensão (.jpg, .png)
4. Abra em arquivo novo para verificar

### Problema: Animações travadas

**Solução:**
1. Atualize navegador
2. Desative extensões do navegador
3. Limpe cache
4. Teste em outro navegador
